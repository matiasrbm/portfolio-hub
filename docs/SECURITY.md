# Política de Segurança

## Versões suportadas
Somente a versão mais recente publicada na branch main recebe correções.

## Como reportar uma vulnerabilidade
Não abra uma issue pública. Envie um e-mail para $EMAIL descrevendo o problema, os passos para reproduzir e o possível impacto. Responderei em até 7 dias.

## Boas práticas adotadas
- Autenticação em dois fatores na conta do mantenedor.
- Branch main protegida; mudanças apenas por pull request.
- Secret scanning e Dependabot ativos.
- Nenhum segredo ou dado pessoal sensível é versionado.
