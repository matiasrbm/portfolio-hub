# Guia de Contribuição

1. Faça um fork do repositório e clone-o.
2. Crie uma branch descritiva: git checkout -b feature/nome-da-mudanca
3. Faça commits pequenos, com mensagens claras (ex.: "docs: adiciona seção de projetos").
4. Envie a branch e abra um pull request explicando o que mudou e por quê.
5. Aguarde a revisão; ajustes podem ser solicitados antes da aprovação.

## Convenções
- Nomes de pastas e arquivos em minúsculas, sem espaços (use hífen).
- Cada projeto tem seu próprio README.md com objetivo, tecnologias, como executar e como contribuir.
- Use issues para relatar bugs e propor melhorias.

## Conduta
Seja respeitoso e objetivo nas revisões e discussões.
